# WRAITH 1.3 — Four-Control Filter

New filter: Cutoff (20 Hz–20 kHz), Resonance (Q approx 0.707–12), Mode (continuous HP→BP→LP), Gain (0–24 dB pre-filter saturation). Filter processes the resonator/reverb wet path, before Mix and Out.

The old Filter parameter remains in the saved state for compatibility but is no longer active. Includes the WRAITH 1.2.1 Cloud Fix processor changes as the base.

Build via GitHub Actions; this source has not been compiled or tested in Ableton Live.
